# Каталог і плаваюча панель 1.9.37

## Реалізовано

- Єдиний каталог із двома модулями: сталі ID, назви, іконки, описи, палітри
  та схема доступних параметрів. Картки й лічильник будуються з каталогу.
- Згорнута картка показує іконку й назву. Натискання відкриває опис, запуск
  панелі, очікування зміни поля та ширину панелі.
- Поведінка спойлерів винесена в `ExpandableSection`: кнопка, фокус,
  оголошення стану й дії розгортання/згортання для служб доступності.
- Очікування зміни поля зберігається окремо для модулів. Під час першого
  звернення кожен успадковує попереднє спільне значення.
- Панель має назву й іконку активного модуля, його колір, текстовий статус
  та одну кнопку `Старт / Стоп`. Основні дії мають область натискання 48 dp.
- Діагностика відкривається натисканням назви/статусу. Вибір зберігається.
- Кнопка `◉` згортає панель до іконки без зупинки сесії. Іконку можна
  пересувати; натискання повертає панель. Кнопка `×` зупиняє й закриває її.
- Ширина 224–360 dp зберігається для модуля; початково 272 dp. Висота
  автоматична. Положення відновлюється окремо для модуля й орієнтації,
  у межах доступної області з урахуванням системних панелей і вирізу.
- Таймери мають власний профіль положення. Поворот екрана відновлює
  відповідний профіль; підтримка ігрових полів залишається портретною.
- Блоки доступу Android й інструкції першого запуску згорнуті. Статус
  доступу видно в заголовку.
- Назва застосунку — «Пелюстка», окремої збірки — «Пелюстка (нова)».
  Номер версії показується внизу головного екрана.

## Ігровий код

Відносно коміту `5b105dd` (реалізація 1.9.36) 19 наявних Java-файлів
розпізнавання, моделей полів, оцінювачів, таймерів та допоміжних класів
залишилися побітово однаковими.

Ділянка служби від запуску автогри до захоплення кадру, стабілізації,
вибору дії й відправлення жесту збереглася. Два читання спільного таймауту
заміщено читанням налаштування активного модуля. При оновленні значення
успадковується; межі, крок, глибина пошуку, пороги й інтервали не змінені.

Код маршрутизації двох полів поки залишається у спільній службі. Каталог
модулів не означає готову систему завантаження плагінів. Межі реалізації та
порядок додавання наступних рушіїв описані в [MODULES.md](MODULES.md).
Ідеї наступних модулів — у [ROADMAP.md](ROADMAP.md).

## Збірка

`assembleDebug assembleRelease`, версія `1.9.37`, `versionCode=68`.
Обидві збірки завершилися успішно; `apksigner verify` підтвердив підпис.
Автоматичні ігрові тести в цьому етапі UI не запускалися; попередні звіти
зберігаються окремо. На фізичному телефоні цей інтерфейс у середовищі
розробки не запускався.

Обидві збірки використовують попередній ключ і ті самі package ID:
`ua.borlock.autotap` та `ua.borlock.autotap.newkey`. Ключ підпису й локальна
конфігурація не входять у репозиторій.
