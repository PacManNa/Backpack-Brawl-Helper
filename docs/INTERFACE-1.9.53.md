# Compact timer interfaces — 1.9.53

Timer cards retain centered labels and separated interval/status columns with less vertical padding and shorter controls. The floating timer panel measures its list content instead of reserving a fixed-height area; it grows to fit a short list and scrolls when the list exceeds the available space. Module cards no longer show speed or panel-width sliders: retries use the minimum 400 ms delay, and floating panels keep a fixed compact width with the collapse-to-icon control available.

Timer behavior and game automation are unchanged.
