# Пелюстка — каталог клікерів і нагадувань

Android-застосунок має два незалежні режими: бот збігів для «Рюкзак-Бліц» і бот 2048 для «Злиття Божевілля». Їхні картки, налаштування й плаваюча панель формуються зі спільного каталогу модулів. Обидва зчитують поле через службу спеціальних можливостей і виконують ходи локально на пристрої.

[Read this README in English](README.en.md)

## Можливості

- Згорнуті картки з іконкою й назвою; опис, запуск і налаштування відкриваються натисканням.
- Незалежний час очікування та ширина панелі для кожного модуля.
- Компактна панель із діагностикою за натисканням, згортанням до іконки та запам’ятовуванням положення.

- Розпізнає сім кольорів самоцвітів, ракету, бомбу та портал-вихор.
- Перевіряє до 112 сусідніх обмінів на полі 8×8.
- Оцінює збіги, бонусні фішки, ланцюгові активації та ймовірні каскади після поповнення поля.
- Розпізнає 17 рівнів щурів у «Злитті Божевілля» на полі 4×4 та вибирає напрямок свайпу пошуком із прогнозом появи нових плиток.
- Показує керування та діагностику у плаваючій панелі **Старт / Стоп**.
- Дозволяє створювати локальні таймери для врожаю, скринь і безкоштовних нагород; сповіщає про завершення та дає перезапустити відлік після дії.
- Обробляє кадри в пам’яті пристрою; застосунок не має дозволу на доступ до мережі.

## Вимоги

- Android 11 або новіший для знімків екрана через службу спеціальних можливостей.
- Портретна орієнтація та одне з полів із підтримуваним розташуванням: «Рюкзак-Бліц» або «Злиття Божевілля».
- Для складання: JDK 17 та Android SDK Platform 35.

## Встановлення й запуск

1. Збери debug APK за інструкцією в [docs/BUILDING.md](docs/BUILDING.md) або встанови вже зібраний файл `app/build/outputs/apk/debug/app-debug.apk`.
2. Відкрий **Пелюстку**, розгорни **Дозвіл Android** та натисни **Увімкнути доступ** і ввімкни службу **Пелюстка — керування грою** в системних налаштуваннях спеціальних можливостей.
3. Повернись у застосунок, натисни назву потрібного модуля, потім **Відкрити панель**.
4. Відкрий відповідну мінігру, дочекайся завершення анімацій і натисни **Старт**. Щоб зупинити автоматичні ходи, натисни **Стоп**.

Для «Злиття Божевілля» потрібне повністю видиме поле 4×4. Бот знаходить межі сітки та прив’язує до неї розпізнавання поля й нижній ланцюжок рівнів; плитки звіряються зі зразками. Якщо кадр нечіткий або рівень не вдалося визначити впевнено, бот повторює знімок і не свайпає.

Щоб користуватися нагадуваннями, відкрий **Налаштувати таймери**, створи таймер із назвою, емодзі та тривалістю. Таймер стартує після створення. Для перегляду відліку в плаваючому меню натисни **Плаваюче меню** на екрані таймерів. Коли таймер завершиться, виконай дію в грі й натисни **↻**, щоб почати наступний відлік. Системні сповіщення можна дозволити під час створення першого таймера.

Дозвіл потрібен, щоб знімати кадри й виконувати свайпи. Служба не читає вміст вікон гри через дерево інтерфейсу. Докладніше: [docs/USAGE.md](docs/USAGE.md).

## Як вибирається хід

Бот «Рюкзак-Бліц» перевіряє обміни по горизонталі та вертикалі, моделює збіги й каскади та оцінює ймовірні поповнення поля. Бот «Злиття Божевілля» перевіряє чотири напрямки, моделює об’єднання однакових рівнів і появу наступних плиток. Більше про обидва режими — у [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

Базова оцінка використовує 50 очок за прибраний самоцвіт при множнику ×1 — за спостереженими ігровими повідомленнями про 4, 5 і 10 фішок. Це оцінка для вибору ходу, а не гарантія фактичного рахунку.

## Обмеження

- «Рюкзак-Бліц» прив’язаний до показаного портретного інтерфейсу; бот 2048 знаходить помірні зсуви сітки за її межами. Зміни теми чи версії гри можуть знизити точність.
- Розпізнавання щурів використовує поточну послідовність іконок під полем і резервні зразки. Перекриті підказки або значна зміна оформлення можуть знизити впевненість.
- Якщо клітинка розпізнана невпевнено або анімація ще триває, бот повторює знімок замість свайпу.
- Напрямок смуги ракети не визначається з кадру; під час оцінювання напрямок моделюється випадково.
- Android обмежує частоту знімків екрана; найкоротший інтервал у сервісі — близько 334 мс, а анімації додають час.
- Оцінювання каскадів використовує випадкове моделювання, тому не передбачає майбутнє поле точно.

## Збірка

З кореня проєкту в Windows PowerShell:

```powershell
.\gradlew.bat assembleDebug --no-daemon --max-workers=1
```

APK буде створено в `app/build/outputs/apk/debug/app-debug.apk`. Інструкції для розробки та складання є в [docs/BUILDING.md](docs/BUILDING.md).

## Конфіденційність і повторне використання

Кадри обробляються на пристрої й не записуються застосунком. У маніфесті немає дозволу на мережу, а резервне копіювання даних застосунку вимкнене. Еталонні знімки для регресій зберігаються в `app/src/test/resources`; кадри під час роботи застосунку не записуються. Локальні налаштування, ключ підпису та результати складання ігноруються Git.

У репозиторії немає файлу ліцензії; умови повторного використання коду не визначені.
